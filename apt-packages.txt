# System packages installed with apt, one per line.

# apt is the first choice for everything: if the Ubuntu archive carries a
# package, it is installed from here. That includes compilers, libraries, and
# services, so Ruby, Python, and gem native extensions build against the same
# packages a GitHub Actions Ubuntu runner has.
#
# Script 01 embeds this file, so editing it re-runs the install on the next
# `chezmoi apply`. Removing a line does not uninstall the package.
